## 🌌 Overview

Welcome to the official portfolio repository of **Sujeevan Vijayendiran**. Designed as a cinematic developer journey, this web application merges high-fidelity 3D graphics, interactive build logs, and clean architectural principles to present an immersive showcase of enterprise software engineering.

Every line of code, animation, and interaction is engineered to reflect a deep commitment to performance, clean architecture, and modern UI/UX design.

---

## 🏗️ System Architecture & Tech Stack

This portfolio is built using a cutting-edge modern web stack, prioritizing high availability, rich aesthetics, and seamless micro-interactions.

### 💻 Frontend Ecosystem
* **Core**: React 19, TypeScript, Vite
* **Styling & Layout**: Tailwind CSS (`@tailwindcss/vite`), Atomic Design Patterns, Glassmorphism
* **Animation & Motion**: Framer Motion (`motion/react`), GSAP (with `ScrollTrigger` for advanced scroll scrubbing)
* **3D & Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), React Three Drei (`@react-three/drei`) for custom Particle Data Highways and volumetric fog.

### ⚙️ Backend & Cloud Expertise (Showcased & Applied)
* **Backend Frameworks**: Spring Boot, REST APIs, Layered Enterprise Architecture
* **Database & ORM**: MySQL, PostgreSQL, JOOQ, Advanced ERD Modeling & Schema Normalization
* **Security & Auth**: JWT (JSON Web Tokens), Role-Based Access Control (RBAC)
* **Cloud Infrastructure**: Microsoft Azure, Azure Blob Storage for enterprise media handling

## 🚀 Getting Started (Run Locally)

To explore, run, or build this cinematic portfolio on your local machine, follow these steps:

### Prerequisites
* **Node.js** (v20+ recommended)
* **Git**

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sujeevan8300/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   *The application will be served locally at `http://localhost:3000` (or the port specified by Vite).*

4. **Build for Production:**
   ```bash
   npm run build
   ```
